# Content Strategy & Layout Mapping

## Global Elements
- **Navigation:** Links to Home, Music, Shows (Coming Soon), Videos, Band, Contact[cite: 3].
- **Footer:** Social links, booking email, and management info[cite: 3].

## Page Requirements

### Homepage (`_index.tsx`)
Must contain the following sections in a highly visual, scrolling layout[cite: 3]:
1. **Hero:** Cuff & Collars title, latest visual/band photograph, and [LISTEN] / [WATCH] calls to action[cite: 3].
2. **Latest Release:** Prominent artwork, title, and streaming links[cite: 3].
3. **Upcoming Shows:** Date, venue, city, and [GET TICKETS] buttons[cite: 3]. (Note: If empty, display "Coming Soon").
4. **Latest Video:** Large, embedded video player[cite: 3].
5. **The Band:** A short statement paired with photography[cite: 3].
6. **Socials:** A visual grid pulling from or linking to Instagram[cite: 3].

### Content Placeholder Rule
If the data for a specific release, show, or band member is not provided in the initialization, the developer (agent) MUST leave a visual `TODO: Insert [Content] Here` marker rather than generating fake placeholder text (Lorem Ipsum) or fake band data[cite: 6].z5z
