# Project Brief: Cuff & Collars Official Website

## The Project
We are building the official website for the alternative/indie band "Cuff & Collars"[cite: 4, 5]. The site must feel like a legitimate, artistic hub for the band—editorial, photographic, and slightly raw[cite: 5]. It should serve as a digital archive and zine, not a corporate landing page.

## Tech Stack
- **Framework:** Remix[cite: 4]
- **Language:** TypeScript[cite: 4]
- **Bundler:** Vite[cite: 4]
- **UI:** React[cite: 4]
- **Styling:** CSS/Tailwind (only if already present)[cite: 4]

## Hard Implementation Rules
1. **No AI Slop:** Avoid SaaS layouts, generic AI-generated aesthetics, excessive rounded cards, glassmorphism, and meaningless whitespace[cite: 5]. 
2. **No Invented Content:** Do not invent band members, songs, venues, or placeholder copy for production[cite: 6]. Use an explicit `TODO` if information is missing[cite: 6].
3. **No Unnecessary Dependencies:** Do not introduce new libraries to solve simple UI problems[cite: 4, 6].
4. **Asset Strictness:** Do not generate replacement imagery; use the provided assets in the `Band Logo` and `RefrenceImages` directories[cite: 2, 6].
5. **No Spontaneous Rewrites:** Do not rewrite the existing project structure unnecessarily[cite: 4].
